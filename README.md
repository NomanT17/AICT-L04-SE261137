## Purpose
This group project outlines a simple process for students to request and reserve shared laboratory equipment. It aims to make equipment availability visible, reduce scheduling conflicts, and help lab staff manage requests.

## Proposed workflow
1. A student views equipment and available booking slots.
2. The student submits a booking request with the required date, time, and purpose.
3. Lab staff approve or reject the request.
4. The booking status is recorded so that overlapping reservations can be avoided.
